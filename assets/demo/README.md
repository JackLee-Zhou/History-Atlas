# 内置演示数据（赤壁）

本目录是“史地舆图”的离线演示数据：一本公版《三国演义》节选、一份人工整理的赤壁态势分析，以及它们依赖的古地名库（`assets/gazetteer/ancient-places.json`）。

> **样板声明**：`assets/demo/analyses/chibi.json` 是**人工整理的内置样板**，不是模型生成结果。它的 `meta.provider = "demo"`、`meta.model = "curated"`，用于无 API key 时演示“原文 → 态势图 → 证据”的完整链路。

## 1. 示例书来源

| 章节 | 来源 URL | 抓取日期 |
| --- | --- | --- |
| 第四十九回 七星壇諸葛祭風 三江口周瑜縱火 | <https://zh.wikisource.org/wiki/三國演義/第049回> | 2026-10-18 |
| 第五十回 諸葛亮智算華容 關雲長義釋曹操 | <https://zh.wikisource.org/wiki/三國演義/第050回> | 2026-10-18 |

- 底本为中文维基文库（Wikisource）收录的《三国演义》全文；作者罗贯中（约1330–约1400）逝世已超过 100 年，作品属于公有领域。维基文库页面版权栏亦标注“此作品在全世界都属于公有领域”。
- 抽取方式：用 `cheerio` 读取页面 `#mw-content-text` 正文，保留回目与全部正文段落（含回中诗），移除页面导航、上一回/下一回、版权栏、编辑链接与样式。
- 文本整理只做版式清理：去掉每段开头的全角缩进和段末空白，段内连续空格归一；**未改动任何字句与标点**。章节正文由段落以 `\n\n` 拼接而成（`Chapter.text`），段落 `start` 由脚本按拼接顺序计算，测试会逐段核对。
- 文本保留了繁体原文，没有转简体，也没有删改。

### 为什么样板分析落在第五十回

`analysis.chapterId = "chi-bi-50"`。第五十回覆盖火攻后的追击、乌林突围、葫芦口伏兵、华容道与关羽释曹操，能在一回之内提供足够的原文证据；第四十九回也已导入，供阅读器浏览。

第 50 回从火攻之后写起，不包含“战前/连环计/群英会”情节（相关情节在更早回目），因此样板三幕按该回实际内容组织为：火攻与江面追击、乌林突围与葫芦口伏兵、华容道与关羽释曹操。

古地名库中的“江陵、襄阳、南郡、许昌、彝陵、合淝、华容道、乌林”等在第 50 回原文都有直接依据。**以下路线因该回没有原文依据，故未编入样板**：

- 曹操“江陵 → 乌林”：第 50 回中的“江陵”只作为曹操询问退路的目的地出现，没有从江陵出发的叙述；不硬编方向。
- 周瑜“柴桑 → 赤壁”：第 50 回未出现“柴桑”。
- 刘备/关羽“樊口 → 夏口”：第 50 回未出现“樊口”；该回只写到关羽放曹后“已回夏口”，因此样板采用“华容道 → 夏口”。
- 黄盖“火船 → 曹军水寨”：第 50 回开场时黄盖已中箭落水，实际进攻水寨的是韩当；样板因此记录“韩当冒烟突火进攻曹军水寨”，不把第 49 回的动作挪到第 50 回。

## 2. 古地名库

- 文件：`assets/gazetteer/ancient-places.json`，共 **122 条**，符合 `lib/schema/gazetteer.ts` 的 `AncientPlace`。
- 覆盖赤壁/官渡相关地点与常见中国历史地名；字段含 `id`、`name`、`aliases`、`category`、`periods`、`modernName`、`admin1`/`admin2`、`lat`/`lng`、`precision`、`confidence`、`source`、`note`。
- 坐标取**今地**（城市/县治/遗址），统一 WGS84，且落在中国及周边窗口 `lng 73–135, lat 3–54` 内。`precision` 为 `site` / `county` / `city`，置信度按“遗址明确 / 县治近似 / 仅到市域”递减。
- 每条 `note` 都说明定位依据或存疑原因。坐标是**示意/近似值**，不是测绘成果；用于本项目的示意地图，不应作为考古或导航依据。
- 具体来源与许可见 `docs/data-sources-demo.md`。**未使用**《中国历史地图集》、CHGIS 或其他受限数据集。

## 3. 赤壁样板分析

- 文件：`assets/demo/analyses/chibi.json`，`id = "demo-chibi-analysis"`，`bookId = "demo-three-kingdoms"`，`chapterId = "chi-bi-50"`，`scope = "chapter"`；`excerpt` 覆盖第 50 回全文，`textHash` 为该回原文的 SHA-256。
- 内容：2 个阵营（曹操军 / 孙刘联军）、15 个地点、7 条路线、2 个控制区、1 条对峙线、3 个场景（赤壁火攻与江面追击 / 乌林突围与葫芦口伏兵 / 华容道与关羽释曹操）、23 条 citation。
- 每个地点/路线/控制区/对峙线至少引用 1 条 citation；场景只引用已存在的地点/路线/区域/对峙线 ID。
- 所有 `citation.quote` 都是第 50 回原文的逐字片段，`start`/`end` **由脚本按 quote 在 `Chapter.text` 中的实际位置计算**，不是手填。空白差异按“连续空白折叠为一个空格”归一化后再核对；`npm run validate:assets` 会列出任何找不到或 offset 错位的 citation 并以非零退出。
- 控制区与对峙线均为 `schematic: true` 的**手工示意几何**（凸包/连线近似），只表达相对态势，不代表实际控制边界或精确阵线。
- 地点坐标来自古地名库（`location.source = "demo"`），不是模型输出；分析中的 `曹军水寨` 为示意营地，位置取乌林江岸，已在 `role` 中注明。

## 4. 许可与署名

- 《三国演义》原文：公有领域；来源为中文维基文库（页面链接见上）。
- 古地名库中标注了 `source.url` 的条目，其今地参考来自**中文维基百科**，按 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) 署名；URL 保留在对应 `source.url` 中。其余条目为项目人工整理的今地资料，来源标签已写明。
- 样板分析、古地名整理与示意几何为本项目人工整理内容，随项目使用。

## 5. 校验与测试

```bash
npm run validate:assets
npx vitest run tests/unit/assets.test.ts
npx tsc --noEmit
```

`validate-assets.ts` 会校验：古地名数量/唯一 id/坐标 bbox/来源/备注、示例书章节与段落偏移、分析 schema 与引用闭合、每条 citation 的 quote 与 offset。测试不联网。
