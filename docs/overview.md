# 天下大势（AI 省域推演）

## 定位

“天下大势”是独立于“本幕态势”的总览模式：

- **本幕态势**：从原文和选区生成，每个地点/路线/控制区都要求 citation；
- **天下大势**：按当前章节年代让模型推演全国省域形势，属于 **AI 历史推演**，不要求回到原文，也不声称精确历史边界。

按钮在阅读器右上角工具栏“整章态势”旁边，点击后以全屏地图打开；关闭返回阅读。

## 数据来源

- 书名、章节标题、当前章节节选（最多约 7000 字）
- 现有分析中的 `period`、势力名、地点名（如果有）
- 模型的历史知识
- `public/basemap/provinces.geojson` 的 31 个省级多边形（Natural Earth，现代边界）

不依赖固定的书目或人工控制表；任何书都可以按章节年代尝试推演。

## 输出

```json
{
  "asOf": { "label": "元末至正二十年", "startYear": 1360, "endYear": 1360, "confidence": 0.6 },
  "powers": [{ "id": "chen", "name": "陈友谅（汉）", "kind": "regime", "color": "#9b2c2c" }],
  "regions": [{
    "province": "湖北省",
    "controllers": [{
      "powerId": "chen",
      "status": "core",
      "confidence": 0.55,
      "note": "江汉一带"
    }]
  }],
  "summary": "……",
  "caveats": ["……"]
}
```

状态：

- `core`：较稳定控制
- `contested`：争夺区
- `nominal`：名义归附
- `presence`：农民军/流动作战/远征军活动区，不等于政权控制

模型只能返回省名，不能返回坐标或自由多边形；服务端按省名校验并着色。

## API

```text
POST /api/overview
{ "bookId": "...", "chapterId": "...", "refresh": false }
```

- 需要配置模型服务；规则模式不会伪造总览。
- 首次生成后按 `bookId + chapterId + period + model` 缓存到 SQLite `overviews` 表。
- `refresh: true` 跳过缓存重新推演。
- “重新推演”按钮会再次调用模型。

## 交互

- 地图按省填色；争夺区用虚线轮廓，活动区低透明度。
- 每个省显示“省名 + 主要势力”标签；鼠标悬停时省份会呼吸式高亮，点击省份查看所有势力、状态、置信度和备注。
- 点击右侧势力列表或左下角势力图例，会高亮该势力控制/活动的所有省份；再次点击取消。
- 右侧面板显示年代、摘要、势力图例、状态图例、模型说明。
- 空白省份表示模型未判断；不是“无主”。
- 全屏模式；关闭后回到阅读器/本幕舆图。

## 已知限制

- 模型的历史知识可能出错，尤其是南明、农民军、同期多政权；结果只作阅读辅助。
- 现代省界不是历史疆域；不能当历史地图或学术结论。
- 第一版不处理外国政权、府县级边界、时间轴、人工校验历史 GIS。
- 无 API key 时不可用；这是 AI 推演模式，不走规则地名词典。
